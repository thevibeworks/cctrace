## Don't repeat
- Whole-dir subsumed predicate under a scoped merge = data loss (a file
  holding an unmerged session's pairs would vanish into no output).
  The strict predicate in planMerge is the fix; keep the test.
- Concurrent-run prune race is safe because the sink appends by PATH
  (appendFileSync recreates a pruned file); don't "fix" it with fds.
- No env twin for --no-auto-merge: only --data-dir/--no-update-check
  have them; adding CCTRACE_NO_AUTO_MERGE was rejected as new surface.
